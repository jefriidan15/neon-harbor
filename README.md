Neon Harbor is a top-down open-world crime game set in a sun-soaked coastal city: steal cars, outrun the Harbor PD, and run five story jobs for Rosa, the garage owner who knows everybody's business.

## Run

```sh
node serve.ts
```

Then open http://localhost:8080 in desktop Chrome.

## Play

- **WASD** — move on foot / drive
- **Mouse** — aim, **click** — shoot
- **E** — enter / exit a car (stealing one raises your wanted level)
- **R** — reload, **M** — job list, **P** — pause

Your progress saves automatically in the browser. The city runs on a day/night clock: the Neon Strip glows after dark, and the police get bolder the more stars you earn.
